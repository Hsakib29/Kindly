Privacy & safety

Control what Kindly reads, and what it sends.

Read page text for context
Off by default. Sends text from the page you are on to Google Gemini when you generate a reply. Turn it off for sites you don't want read.
Mask card and token numbers
Hides likely card numbers and API tokens before sending text. Always on.

What Kindly sends, and when

Kindly has no account, no server of its own, and no analytics. Text is sent to Google Gemini only when you press Generate, using your own API key.

With page context off, only the text you typed is sent. With page context on, text from the page is sent as well, after masking card and token numbers. The full policy is in the project's docs folder.
